# 카이로스 (kairos-app)

민진 리 예일대 축사(2026)의 크로노스/카이로스 개념을 바탕으로 만든 개인용 기록 앱.

**주소:** https://yeonheekim-prog.github.io/kairos-app/

## 탭 4개

| 탭 | 하는 일 |
|---|---|
| ☀️ 오늘 | 아침 1줄(오늘의 중요한 것 1개) · 밤 1줄(의미 있었던 순간) · 미룬 일 |
| 📖 회고 | 지난 7일 기록 자동 정리 + 4칸 회고. **일요일에 열면 자동으로 이 화면이 뜬다** |
| 🎬 유튜브 | 소재 3칸 (①한국과 다른 점 ②당황 포인트 ③미리 알았으면 준비했을 것 ← 쿠팡 상품) |
| 🌱 기록 | 씨앗 최대 3개 · 통계 · 전체 기록 · 텍스트 내보내기 |

## 기술

- 단일 `index.html`, 외부 의존성 없음
- 저장: `localStorage` 키 `kairos_v1`
- 일요일 자동 회고: `getDay()===0` && 이번 주 회고 미작성 && 하루 1회(`lastAuto`)
- 주 기준: 가장 최근 일요일 날짜를 `week` 키로 사용
